=== Remote Control Dialog

image::mediaplayer-01.png[]

The remote control dialog is displayed using the OpenCPN toolbar button

image::mediaplayer-02.png[]

The control allows you to play and control many of the media player functions

[cols=",,",options="header",]
|===
|Control |Function |Notes
|Power | Switch unit on/off|
|Next |Play next track | USB^1^ 
| | Next Station | radio^2^
|Previous | Play previous track | USB ^1^
| | Previous Station| radio^2^
|Pause| Pause playing | USB^1^
|Play | Resume playing| USB^1^
|Save |Save current station as preset| radio^2^
|Mute |Mute sound| 
|Unmute |Restore sound level|
|Media List |Navigate folders and music tracks| USB^1^
|Media List |Display preset radio stations| radio^2^
|Media List | Context menu |
|Source |Select available input sources|
|Status | Display name of current track and elapsed time| USB^1^
|Status | Display band, frequency and RDS | radio^2^
|===

1. Any of the supported USB devices including USB memory sticks, MTP devices 
(MP3 players), Android devices. Apple iPods may work although untested as I
do not have access to one.
2. Radio inputs such as AM or FM. DAB or SiriusXM are not supported (only because
I do not have access to either)

=== Settings Dialog

image::mediaplayer-03.png[]

The plugin preferences dialog allows you to configure a few of the media player's 
settings. None of the media player settings are stored in OpenCPN, they are stored in 
the Fusion Media Player unit.

image::mediaplayer-05.png[]

While it does not replace the functionality present in the Fusion devices. it allows you
to configure a few settings such as the device and zone names, zone volume limits and some  
tuner settings such as radio region, tuning steps (in Hz) and to delete stored preset
radio stations.
